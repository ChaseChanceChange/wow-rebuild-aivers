# Style Bible

This file will define the visual direction once the first few missions prove the pipeline works.

Until then, the temporary rule is:

> Prefer clean, readable, slightly stylised forms that work well at 3.3.5 distances and lighting.  
> Avoid pure realism that fights the original animation and camera distances.  
> Consistency across newly added assets is more important than matching any single external art style.

Agents must not invent a full art direction.  
When a mission requires visual decisions, make the smallest reasonable choice, document it in the field note, and leave larger direction decisions for the human.
