# Knowledge Base

Field notes written by agents (and humans) after completing missions.

Each note should contain:

- Exact tool and client/server versions
- The route that was taken
- Commands that worked
- Gotchas in the form **symptom → cause → fix**
- What was verified in-game and what was left untested
- Links or paths to the relevant assets and patches

Name notes clearly, for example:

- `bootstrap.md`
- `first-model.md`
- `character-base.md`
- `tiny-zone.md`

When a note is generally useful beyond this repository, consider also contributing it upstream to the Universal Modder knowledge base (with human approval).
